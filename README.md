# สืบศิลป์ไทย — ศิลปะและวัฒนธรรมไทย

เว็บไซต์ต้นแบบเพื่อการเรียนรู้ พัฒนาด้วย HTML5, CSS3 และ JavaScript แบบ Static ไม่ต้องติดตั้งแพ็กเกจ

## ไฟล์
- `index.html` — โครงสร้างหน้าเว็บและเนื้อหา
- `style.css` — สี รูปแบบ Responsive และแอนิเมชัน
- `script.js` — เมนูมือถือ การค้นหา/กรองหมวดหมู่ หน้าต่างเรื่องราว และแบบทดสอบ
- `SOURCES.md` — แนวทางตรวจสอบข้อมูลและรูปภาพ

## เปิดใช้งาน
1. ดาวน์โหลดหรือ Clone repository นี้
2. เปิด `index.html` ในเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server ใน VS Code
3. เว็บไซต์โหลดฟอนต์จาก Google Fonts และภาพ Hero จาก Unsplash จึงต้องเชื่อมต่ออินเทอร์เน็ตสำหรับองค์ประกอบภายนอกดังกล่าว

## เผยแพร่ด้วย GitHub Pages
1. เข้า Settings ของ repository
2. เลือก Pages
3. ใน Build and deployment เลือก Deploy from a branch
4. เลือก branch `main` และโฟลเดอร์ `/(root)` แล้วกด Save
5. รอ GitHub สร้างเว็บไซต์ จากนั้นเปิด URL ที่แสดงในหน้า Pages

## หมายเหตุด้านเนื้อหา
การ์ดและคลังภาพใช้กราฟิก CSS เชิงตกแต่ง ไม่ใช่ภาพถ่ายหลักฐานของวัตถุหรือประเพณีจริง เนื้อหาเป็นบทนำและควรตรวจสอบรายละเอียดจากแหล่งอ้างอิงก่อนนำไปใช้เป็นสื่อการสอนอย่างเป็นทางการ
